# Excalidraw-Style Method Diagram Guide

## 1. Target Look

Use a clean, hand-drawn technical style similar to Excalidraw:
- Whiteboard-like background
- Slightly rough, sketch-like outlines
- Flat color fills (no gradients, no glossy shading)
- Simple, readable flowchart composition

The diagram should feel informal in stroke quality, but precise in structure.

---

## 2. Core Style Rules

### A. Shapes and Strokes

- Prefer rounded rectangles, pills, circles, and simple containers.
- Use slightly irregular/rough borders to mimic marker-like drawing.
- Keep stroke thickness consistent across related elements.
- Avoid photorealistic icons and detailed textures.

### B. Colors

- Use muted, friendly tones (soft blue, light green, warm orange, pale yellow).
- Keep fills light so labels remain readable.
- Use a limited palette (3-5 main hues) to avoid clutter.
- Use darker stroke shades of the same hue for borders.

### C. Connectors

- Use clear arrows with enough spacing from text.
- Prefer mostly straight or gently curved connectors.
- Dashed connectors should indicate optional/auxiliary flow only.
- Keep arrow style consistent within the same semantic category.

### D. Typography

- Use clean sans-serif labels with high readability.
- Keep label text short and explicit.
- Ensure all labels are English and correctly spelled.
- Do not include figure titles inside the image.

### E. Composition

- Maintain a single clear flow direction (left-to-right or top-to-bottom).
- Keep spacing consistent between sibling components.
- Use grouped containers to separate stages/phases.
- Preserve whitespace to prevent visual crowding.

---

## 3. Things to Avoid

- Ultra-polished poster aesthetics or glossy conference infographics
- 3D effects, shadows, bevels, lens flares
- Dense micro-details that hurt readability
- Random decorative icons without semantic purpose
- Saturated backgrounds that overpower content

---

## 4. Domain Adaptation

For all domains (agent systems, vision, theory, generative models):
- Keep the same Excalidraw-like hand-drawn base style.
- Adjust only semantic symbols and layout patterns for the domain.
- Prioritize faithful method communication over decorative styling.
